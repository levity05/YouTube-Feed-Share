# YouTube Feed Share

[English](README.md) · **Русский**

> Сделайте снимок своего YouTube и поделитесь им. Плюс текст видео, AI-сводки, СДВГ-режим без «воды», фильтр ленты, аудио-режим с синхронным текстом и надёжное «продолжить просмотр».

Расширение для Chrome, которое работает прямо на youtube.com. Сервера и аккаунта нет: всё хранится у вас в браузере.

---

## ✨ Возможности

| | |
|---|---|
| 📦 **Снимки ленты** | Главная, «Посмотреть позже», история и Shorts собираются в один снимок. Его можно отправить JSON-файлом или кодом. Друг смотрит снимок во встроенном «микро-YouTube»: вкладки, плеер, статистика, сравнение снимков («Что нового?»). |
| 📝 **Текст видео** | Расшифровка любого ролика, с тайм-кодами или без. Можно копировать или скачать как `Название - Канал.txt`. Клик по времени перематывает видео. Язык — как у YouTube: сначала язык звука, затем основные субтитры. |
| ✨ **AI-сводки** | Gemini по вашему бесплатному ключу [Google AI Studio](https://aistudio.google.com/apikey). В сводке: теги смысла, краткое содержание, главное, хронология с кликабельными тайм-кодами и «кому полезно». Шесть пресетов: Стандарт, Кратко, Подробно, Конспект, Факты и цифры, Ответ на заголовок. Встроенные промты написаны на всех 12 языках интерфейса и меняются вместе с языком; их можно править (для каждого языка своя правка) и добавлять свои. |
| ⚡ **СДВГ-режим** | Gemini читает текст ролика и размечает его: ▶ главное — смотреть, ⏩ медленное — 1.5–2×, ⏭ «воду» — пропустить. Дальше режим сам ведёт просмотр и в паре слов пишет поверх видео, что пропустил (с кнопкой «↩ Вернуть»). Под плеером — цветная полоса плана; «Мягко / Норм / Жёстко»; любую часть можно поменять вручную. |
| 🎛 **Фильтр ленты** | Пересобирает главную, подписки, поиск и рекомендации рядом с роликом: скрыть Shorts, трансляции, премьеры, просмотренное и миксы; фильтр по длительности, языку заголовка, каналам, словам и #хештегам; «только музыка»; сортировка по новизне, просмотрам, длительности. Или **показать ленту группами**: по авторам, типу, длительности, языку, хештегам. Расширение само находит всю музыку: включает чипы «Музыка» и «Джемы», нажимает «Ещё», листает ленту и достаёт треки из миксов. |
| ⭐ **Подборка по вкусу** | Смотрит на последние ~100 роликов вашей истории и находит похожие в загруженной ленте — **без AI** (обычный расчёт по темам, каналам, длительности и языку), с мини-описанием каждого ролика и причиной выбора. 1, 3, 5 или 10 роликов; 👍 / 👎 обучают подборку. По желанию один короткий запрос к Gemini выберет лучшие и объяснит почему. |
| 🎵 **Музыка** | Узнаёт музыкальные ролики, собирает из треков на странице очередь и играет подряд («▶ Слушать подряд» — кнопки наушников переключают треки), кнопка **«Где послушать»** под любым треком находит его на Spotify, Apple Music, Яндекс Музыке, YouTube Music, SoundCloud, Deezer и VK. |
| 🧠 **Самопочинка парсера** | У парсера есть запасные пути (общий поиск id, ссылки в DOM). По желанию, если YouTube сменит формат карточек, Gemini посмотрит на 2–3 обрезанные карточки и вернёт «рецепт» — пути к полям. Это данные, а не код; рецепт проверяется на том же ответе, прежде чем начнёт работать. |
| ⚖️ **Балансировщик моделей** | Если модель перегружена или закончилась квота, расширение повторяет запрос или переходит на следующую модель (flash → flash-lite → pro). «Размышления» выключены ради скорости. Сводки кэшируются для каждого пресета отдельно. |
| 🎧 **Аудио-режим** | Плеер и рекомендации скрыты, на экране — вид «как в музыкальном приложении»: текст по центру, полоса плеера внизу (обложка, главы, громкость, скорость, таймер сна, предыдущий / следующий трек) и очередь, выезжающая справа. Текст видео **идёт синхронно со звуком**: текущая строка подсвечена и сама прокручивается, клик по строке перематывает. Качество видео снижается до минимума, чтобы экономить трафик. |
| 📡 **Трансляции** | Удобная раскладка трансляции (чат на всю высоту, ширина меняется, слева или справа) и собственный чат в стиле Twitch (расширение рисует чат само, а у YouTube берёт только сообщения): сообщения одной строкой, значки, вкладки переписок (группа или один человек) с ответами, подсказка ников по «@», строка «чат приостановлен», время ЧЧ:ММ, цвета ников Twitch, наборы смайликов (Twemoji, Apple, Google, Facebook, OpenMoji), смайлики 7TV / BetterTTV / FrankerFaceZ (общие, ивентовские, собственные смайлики канала трансляции и любого стримера по имени), подсветка и звук при упоминании, ответ по клику на ник, мини-чат только с выбранными людьми, скрытие ботов и команд, история сообщений человека. |
| ⏯ **Продолжить просмотр** | Расширение само запоминает, где вы остановились (YouTube иногда забывает). В popup — последние 5 недосмотренных роликов, нажатие открывает ролик ровно с этого места. |
| ⚡ **Shorts** | Автолистание. Пропуск по длительности, автору и хештегу. Кнопки наушников и медиаклавиши листают шорты, даже когда окно без фокуса (второй монитор). |
| 🌍 **12 языков** | English, Русский, Українська, Español, Português, Français, Deutsch, Italiano, Polski, Türkçe, 日本語, 简体中文. |

## 🚀 Установка

Расширения пока нет в Chrome Web Store, поэтому оно ставится в режиме разработчика:

1. Скачайте `youtube-feed-share-v4.6.0.zip` из [последнего релиза](https://github.com/levity05/YouTube-Feed-Share/releases/latest) и распакуйте. Или склонируйте репозиторий: `git clone https://github.com/levity05/YouTube-Feed-Share.git`.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку, где лежит `manifest.json`.
4. Закрепите значок расширения и откройте любой ролик на YouTube.

Чтобы обновиться: замените файлы, нажмите **Обновить** на карточке расширения и перезагрузите вкладки YouTube.

## 🧭 Быстрый старт

**На странице ролика**
- Под названием видео три кнопки: **📝 Текст видео**, **✨ Краткая сводка**, **🎧 Аудио-режим**. Такие же есть в popup.
- Для сводок вставьте бесплатный ключ Gemini в **⚙ Настройки → AI-сводки** (или прямо в панели) и нажмите **Проверить**.

**Поделиться лентой**
1. Popup → вкладка **📦 Снимок** → отметьте разделы → **Собрать снимок**. Расширение само откроет разделы и прокрутит их.
2. **Проверить и поделиться**: скройте всё, чем не хотите делиться, особенно в истории.
3. Отправьте **JSON-файл**. Друг перетаскивает его в просмотрщик (popup → 📺) или нажимает Ctrl+V с кодом.

**Продолжить просмотр** — popup → вкладка **▶ Смотреть**.

## ✨ Подробнее об AI-сводках

- **Ваш ключ — ваша квота.** Ключ хранится только в этом браузере (`chrome.storage.local`) и отправляется только на `generativelanguage.googleapis.com`.
- **Пресеты.** Промты собраны из общей основы:
  - на входе обычно автоматическая расшифровка с ослышками;
  - только факты, без «воды», конкретика с цифрами;
  - мнения подаются как мнения;
  - нужен ответ на вопрос из заголовка;
  - тайм-коды копируются из расшифровки;
  - перед ответом модель молча себя проверяет.

  У каждого пресета своя задача и требования к полям. В русском интерфейсе промты на русском. Править: ✎ в панели или **Настройки → Пресеты сводки**.
- **Нет текста?** Тогда Gemini смотрит сам публичный ролик по ссылке.
- **Балансировщик.** При ошибке 503 — повтор через ~1 секунду, потом следующая модель. При 429, 404 или таймауте модель меняется сразу. Занятые модели «остывают» 2–10 минут. Ход генерации виден, есть «Отмена».

## 🔒 Приватность

- Ни сервера, ни аналитики, ни слежки. Снимки, места остановки, сводки и настройки лежат в `chrome.storage.local`.
- Запросы уходят только на YouTube (как от вашей же страницы) и, если вы добавили ключ, в Gemini API от Google.
- Снимок может содержать **историю просмотра**. Проверьте его перед отправкой.

Подробно: [PRIVACY.md](PRIVACY.md) (на английском).

## 🌐 Просмотрщик без расширения

`src/viewer/viewer.html` — обычная статическая страница, поэтому другу расширение не обязательно:

1. Опубликуйте репозиторий через **GitHub Pages**: Settings → Pages → Deploy from branch.
2. Вставьте `https://<имя>.github.io/<репозиторий>/src/viewer/viewer.html` в **Настройки → Обмен снимком**.
3. Теперь кнопка **Копировать** выдаёт готовую ссылку. Данные лежат во фрагменте `#…` и на сервер не отправляются.

Локально: `python -m http.server 8765` → <http://localhost:8765/src/viewer/viewer.html>. Если открыть файл двойным кликом (`file://`), видео не играют (ошибка YouTube 153).

## 🛠 Как устроено

| Путь | Что делает |
|---|---|
| `src/background.js` | Проводит сбор снимка; разрешает страницам YouTube играть внутри просмотрщика расширения (правило DNR только для фреймов самого расширения); передаёт запросы к Gemini |
| `src/content/hook.js` | Контекст страницы (MAIN): ответы ленты, команды плееру YouTube (субтитры, качество) |
| `src/content/collector.js` | Сбор на странице: прокрутка, фильтры, дни истории, Shorts |
| `src/content/watchtools.js` | Кнопки и панель «Текст / Сводка» на youtube.com/watch |
| `src/content/audiomode.js` | 🎧 Аудио-режим с синхронным текстом |
| `src/content/resume.js` | ⏯ Запоминание места остановки |
| `src/content/focusmode.js` | ⚡ СДВГ-режим: план, управление просмотром, полоса плана |
| `src/content/feedfilter.js`, `src/shared/feedrules.js` | 🎛 Фильтр ленты: панель на YouTube и правила (чистые функции) |
| `src/shared/taste.js` | ⭐ Вкус: слова и основы, профиль из истории, ранжирование карточек ленты, мини-описание (чистые функции) |
| `src/shared/music.js` | 🎵 Трек или нет, «Исполнитель — Трек», ссылки на площадки, очередь |
| `src/content/loop.js` | Один общий таймер для всех content scripts (в фоновой вкладке почти не работает) |
| `src/content/ytfetch.js` | Получение текста видео несколькими способами (панель YouTube, подписанные субтитры, запасные пути) |
| `src/shared/parse.js` | Парсер «сначала ID»: известные форматы YouTube, общий поиск ID, ссылки в DOM, детектор поломки |
| `src/shared/ai.js` | Gemini: один вызов «JSON по схеме» с балансировщиком, пресеты промтов (тексты — ключи `prompt.*` в словарях), план СДВГ-режима, рецепт ремонта парсера |
| `src/shared/transcript.js` | Разбор текста видео и форматирование |
| `src/shared/feed.js` | Формат снимка v2, код `YFS2.` (deflate + base64url) |
| `src/viewer/*` | Просмотрщик «микро-YouTube»: библиотека, вкладки, Shorts, статистика, сравнение, плеер, панель текста |
| `src/popup/*`, `src/options/*`, `src/shorts/*` | Popup, настройки, настройки Shorts |
| `src/locales/*`, `_locales/*` | Переводы (`en.js` — основной словарь) |

<details>
<summary>Формат снимка (v2)</summary>

```json
{ "format": "yt-feed-share", "version": 2, "exportedAt": "…", "author": "…", "lang": "ru-RU",
  "feeds": [
    { "type": "home",        "videos": [{ "id": "…", "title": "…", "channel": "…", "duration": "10:23" }] },
    { "type": "watch-later", "videos": [] },
    { "type": "history",     "videos": [{ "id": "…", "watchedDay": "2026-10-05", "progress": 75 }] },
    { "type": "shorts",      "videos": [{ "id": "…", "short": true }] }
  ] }
```

Ролик — это прежде всего его `id`. Недостающие данные (`"title": null`) просмотрщик восстанавливает через oEmbed или страницу ролика. Превью строятся из `id`.
</details>

## 🧪 Разработка

```bash
node test/run.js
```

Зависимостей и сборки нет: обычный JavaScript, который грузится как есть. Тесты проверяют:
- парсер — на настоящих образцах ответов YouTube в `test/fixtures/`;
- формат снимка;
- переводы: все ключи, подстановки и формы множественного числа во всех языках;
- разбор текста видео;
- клиент Gemini вместе с балансировщиком.

Если YouTube сломал сбор, в popup есть **Скачать образец для отладки**. Положите его в `test/fixtures/` с полем `expect: { "ids": [...] }` и правьте `src/shared/parse.js`, пока тесты не пройдут.

Как добавить язык, пресет или исправление — в [CONTRIBUTING.md](CONTRIBUTING.md).

## ⚠️ Известные ограничения

- YouTube часто меняет разметку и внутренние API. У парсера и получения текста есть запасные пути, но иногда что-то будет ломаться.
- Даты истории распознаются по заголовкам дней только в русском и английском интерфейсе YouTube.
- Собранные Shorts YouTube считает просмотренными, они могут повлиять на рекомендации.
- Полный снимок из четырёх разделов в виде кода — это десятки тысяч символов. Отправляйте JSON-файл.
